# Seguridad

Para comunicar una vulnerabilidad, abre una incidencia privada con el mantenedor o utiliza la información de contacto indicada en el repositorio. No publiques credenciales IPTV, enlaces privados ni archivos de lista.

Las versiones distribuidas deben estar firmadas con la clave de producción de OpenStream TV y verificarse con `apksigner` antes de publicarse. Las APK debug o sin firmar no son versiones de distribución.
