# OpenStream TV — documentation

Reproductor IPTV open source para Android TV y Amazon Fire TV. Importa M3U/M3U8, Xtream Codes y XMLTV; mantiene favoritos e historial local y usa Media3/ExoPlayer con reconexión, búfer y diagnóstico.
