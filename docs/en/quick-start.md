# Quick start

With JDK 17 and Android SDK 36, run `./gradlew lintTvDebug lintMobileDebug testTvDebugUnitTest testMobileDebugUnitTest assembleDebug`. Install the TV or mobile APK for your device and add an authorized M3U or Xtream source and an optional XMLTV guide.

Configure secrets through the environment or a provider secret manager. Do not upload .env files, credentials, tokens, keystores, or private playlists.
