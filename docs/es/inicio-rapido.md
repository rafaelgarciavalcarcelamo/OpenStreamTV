# Inicio rápido

Abre con JDK 17 y SDK 36; ejecuta ./gradlew.bat lintDebug testDebugUnitTest assembleDebug; instala el APK; añade una fuente M3U o cuenta Xtream autorizada y, opcionalmente, XMLTV; usa INFO/MENÚ para diagnóstico.

Configura secretos mediante el entorno o el gestor de secretos. No subas .env, credenciales, tokens, keystores ni listas privadas.
