# Inicio rápido

Con JDK 17 y SDK 36, ejecuta `gradlew.bat lintTvDebug lintMobileDebug testTvDebugUnitTest testMobileDebugUnitTest assembleDebug`. Instala la APK de TV o la de móvil según el dispositivo y añade una fuente M3U, una cuenta Xtream autorizada o una guía XMLTV opcional.

Configura secretos mediante el entorno o el gestor de secretos. No subas .env, credenciales, tokens, keystores ni listas privadas.
